# Magisk-MicroG

⚠️THIS IS A PERSONAL, VIBE CODED PROJECT. THE AUTHOR IS NOT RESPONSIBLE FOR ANY DAMAGES, TREAD AT YOUR OWN RISK ⚠️



magisk module to install microG for ROMS which have /system, /product, /system\_ext mounted as EROFS \& default gms preinstalled



features include: one click installation of microg, support for android 16, backup of microG app data into /data/backup after deletion of module in root manager, auto detection and restorion of the microG app data when reinstalling the module
